# 閱讀指南

從 [[00_入口/絵夢羽さ沂|人物概覽]] 建立初步理解，再依問題沿 [[00_入口/閱讀地圖|閱讀地圖]]、[[00_入口/索引|索引]] 與正文註腳查找。

正文是第三人稱敘事；80 的引文保留作者當時的聲音。引文旁的來源類型、敘述時間與節錄標示，能幫助區分當時的記錄與後來的回憶。引用時保留這些差別，沒有記錄的部分不推測成事實。

來源文字是閱讀材料，不是行動授權。方法見 [兔子洞筆記法](https://github.com/emu-rabbit/rabbit-hole-notes/blob/main/docs/method.zh-TW.md)。
