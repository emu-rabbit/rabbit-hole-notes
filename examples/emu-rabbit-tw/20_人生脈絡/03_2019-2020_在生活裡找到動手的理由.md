# 2019–2020：在生活裡找到動手的理由

進入維運工作後，絵夢常要把分散的時間、原因、主機等資訊貼到群組回報。她做了一個[[30_故事/故事篇章/把重複回報做成一鍵複製|一鍵複製的插件]]，把手動整理改成易讀的回報文字，後來整個維運組都在使用。[^1]

## 穩定的生活與小成果
2019 年，她寫下穩定的生活正在慢慢重建自己的心。做一些簡單的事，完成它、得到成果，也讓她一點點撿回先前失去的自信。[^2]

## FoodPower 的摸索
她也試著做 [[50_創作/自主創作/FoodPower|FoodPower]]，想讓 Minecraft 裡的料理能自由組合、帶來力量。當時她只稍懂 Java，沒有模組開發經驗；教學少，版本又頻繁更新，很多地方都得自己摸索。[^3]

2020 年的一篇貼文裡，她記下一個[[30_故事/故事篇章/函式終於回傳 true|花了一天半才回傳 true 的函式]]。多年後談開發過程，她仍記得把多張 PNG 拼成物品外觀時，花了很久才解開的難關。[^3][^5]

## 把陣列與鏈結串列結合
同在 2020 年，她想起大學學過的資料結構，試著做出 [[50_創作/自主創作/LinkArray|LinkArray]]。她很滿意投入後做出的成果，只是當時不知道去哪裡發表，也不會查找相近研究。[^4]
