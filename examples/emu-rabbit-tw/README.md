# 絵夢羽さ沂的兔子洞
## Emu-rabbit's Rabbit Hole

絵夢喜歡寫程式、玩遊戲，也喜歡寫下自己的生活。這裡收下她幾段學習、創作、穿著與相處的經歷，讓你從一件作品走到一段回憶，或從一個人讀到一起度過的時光。

這是她依兔子洞筆記法整理的公開精選，共 58 篇筆記。它保留人物代稱與來源節錄的標示，呈現的是她願意在這裡分享的幾個面向。

## 沿著連結讀

正文以第三人稱敘事，註腳通往 [[80_來源/來源目錄|來源]]。那裡保留作者的原話，也標明當時的記錄、後來的訪談與節錄範圍。可以停在故事，也可以多走一步，對照當時寫下的話和後來的回看。

這份精選用一篇索引帶到各區，沒有另附故事目錄、創作目錄、關係圈或維護區。[兔子洞筆記法](https://github.com/emu-rabbit/rabbit-hole-notes/blob/main/docs/method.zh-TW.md)說明的是可持續生長的完整方法；建立自己的洞時，再依內容需要展開。給 agent 的入口是 [[AGENTS|閱讀指南]]。

## 下載後，在自己的閱讀工具裡走走

網站閱讀器的「下載範例」可取得這份中文筆記的 ZIP。英文閱讀器提供獨立的英文版，兩份內容範圍相同。

1. 解壓縮 ZIP，保留資料夾結構。
2. 在 Obsidian 選擇「開啟資料夾為儲存庫」（Open folder as vault），選取含 README.md、00_入口、10_自我與生活、20_人生脈絡等資料夾的那一層。
3. 開啟 README.md，切到閱讀模式，從上面的一條短路線開始。

不需要社群外掛。一般文字編輯器也能閱讀 Markdown；雙中括號連結與區塊定位可在 Obsidian 或網站閱讀器使用，直接在 GitHub 檔案頁瀏覽時不會全部變成可點選的連結。
