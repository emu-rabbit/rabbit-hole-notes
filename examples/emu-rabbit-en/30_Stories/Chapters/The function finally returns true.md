# The function finally returns true

In 2020, Emu-Rabbit recorded a problem she ran into during development: a function looked as though it could help, but she did not know how it worked. It had comments, but she could not understand them. For a full day and a half, she tried passing in all kinds of parameters and kept getting false. When it finally returned true, she wrote a post about it.[^1]

Years later, recalling the development of [[50_Creative work/Independent work/FoodPower|FoodPower]], she still remembered the image-compositing hurdle. She wanted to combine multiple PNGs into the appearance of a Minecraft item, but could not understand the source code or find tutorials. It took her a long time to work it out. She recalled having written a Facebook post about it.[^2]
