# Begin a rabbit hole

Help the owner start with something worth keeping. A memory is enough; a collection of exported records is optional.

Read the [shared conventions](references/conventions.md) on first use; they provide the offline core principles and structure. Establish only what is still unknown: owner, language, private location, and whether this conversation may be saved. Use the existing agreement and vault guidance when continuing.

## Make the first useful piece

1. For a new vault, preview initialization with the [local helper](references/cli.md), then apply within the approved location. For an existing vault, read its entrance and continue its structure.
2. Follow the owner's starting point. For a memory, use the [conversation guidance](references/conversation.md) and ask one easy question. For supplied records, follow the [import workflow](../rabbit-hole-import/SKILL.md) for the selected batch. Continue the task yourself; the owner can answer naturally without invoking another skill.
3. At a natural stopping point, complete the [saved-work workflow](references/finish.md): preserve the account, integrate supported notes, update navigation and progress, then read and check the result.
4. Return a short description and an entrance to the result. Distinguish a setup-only structure from a readable first account.

Honor a request to set up only or to chat without saving. A first saved memory is complete when a newcomer can understand it, reach it from the entrance, and return to its attributed source.

## Examples

- 「幫我建立兔子洞。我想從第一次搬家聊起。」
- “Start a rabbit hole for me. I'd like to begin with the first time I moved home.”
