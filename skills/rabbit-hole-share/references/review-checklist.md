# Review the actual reading copy

Review the staged bytes and the reader’s experience, then record the outcome privately.

## Selection and disclosure

- The draft has a clear audience, purpose and content boundary chosen by the owner, with its exact file selection documented for review.
- Every page and asset has been read in full, including metadata, aliases, filenames, captions, and source excerpts.
- Disclosure review covers each person’s information and indirect identification through quotations, dates, nicknames, relationships, or combined clues. Apply the required authorization for sensitive information and information about minors.
- The copy contains only selected material. Master history, hidden files, raw archives, originals, ledgers, maintenance, and caches remain outside it.
- Redactions remove the text from actual file bytes. Excerpts retain accurate attribution, timing, omissions, and translation status.

## A self-contained reading experience

- Markdown links, Wiki links, embeds, and footnotes lead to approved included material or intentionally approved external destinations. Check URLs, query strings, and fragments for disclosure too; inspect remote references without automatically fetching assets.
- Dependencies on excluded material have an approved, truthful resolution. Source references accurately describe what the reader can access.
- README gives this copy’s scope and entry choices; specific routes belong in the reading map. AGENTS describes the included material, question-led lookup, source checks, and authorization for actions beyond reading. Keep private maintenance instructions outside a public reading copy.
- README and AGENTS link to one another and to included entry files with relative Markdown links. Keep a small copy’s single Start when appropriate; do not create empty profile, map, or index pages to imitate a larger vault.
- Walk both routes: README → chosen entry → narrative → source → return, and AGENTS → question-led lookup → source verification → README. Verify links in the intended interfaces, distinguishing file-target checks from actual interface use.

## Review and delivery

- The owner reviewed the final pages, source excerpts, assets, and changed navigation for this audience. Record the exact version approved; material changes receive renewed review.
- Delivery authorization identifies final files, audience/recipient, access level, and destination. A prepared file or accepted send is reported as such until delivery or access is verified.

Keep the selection and review record in the private workspace, separate from the reading copy. Later correction or withdrawal may require replacing files and checking existing shares; downloaded copies cannot be revoked by this toolkit.
